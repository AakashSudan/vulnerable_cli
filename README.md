# 🛡️ Vulnerable CLI Toolkit

A command-line tool for simulating and testing basic web application vulnerabilities like **SQL Injection**, **Cross-Site Scripting (XSS)**, and **Brute-Force Attacks** using a DVWA (Damn Vulnerable Web App) instance.

> ⚠️ **For educational and ethical hacking purposes only.**
> Do not use this toolkit against unauthorized targets.

---

---

## ⚙️ Requirements

- Python 3.x
- Selenium (`pip install selenium`)
- Requests (`pip install requests`)
- BeautifulSoup4 (`pip install beautifulsoup4`)
- ChromeDriver (for brute-force script)

---

First, ensure you are running [DVWA](http://www.dvwa.co.uk/) locally (`http://localhost/DVWA`).
